# Using Haul

## Add a download

Press **⌘N**, or paste a link with **⌘V**, or drop a link onto the window. Haul checks the link, suggests a name and a folder, and you press **Start**. Files go into a folder for their type (Videos, Music, Documents…); you can change each folder in Settings, Save to.

## Pause, resume and keep going

- **Pause** and **Resume** are on every row. Paused downloads carry on from where they stopped, even after you quit Haul.
- If a connection drops, Haul retries by itself.
- Closing the window does not stop anything. Haul stays in the menu bar; click its icon or the Dock icon to bring the window back. **⌘Q** quits, and asks first if downloads are running.

## Take over downloads from your browser

Install the Haul extension in Chrome or Firefox, then:

1. In Haul, open **Settings, General** and press **Copy token**.
2. In the browser, open the extension's options and paste the token.
3. Press **Test connection**. It should say *Connected*.

After that, clicking a download link for a zip, disk image, video and so on sends it to Haul. Right-click any other link and choose **Download with Haul**. If Haul is closed, your browser just downloads the file as usual.

Choose which file types, how big, and which sites to leave alone in **Settings, File types**.

## Make it yours

- **Speed limit, connections and retries:** Settings, Connection.
- **Proxy:** Settings, Proxy.
- **Sites that ask for a login:** Settings, Site logins. Passwords are kept in your Keychain.
- **Banners and sounds** when a download finishes or fails: Settings, Notifications.
- **Open at login, start hidden, keep the Mac awake:** Settings, General.

## When something goes wrong

- **A row says why it failed.** Press **Retry**. If it says the link has expired, press **New link** and paste a fresh one.
- **The extension says Haul did not answer.** Check that Haul is running, that **Take over downloads from browsers** is on, and that the port in the extension's options matches the one in Haul's Settings, General.
- **The token was not accepted.** Press **Copy token** in Haul again and paste it fresh.
- **A download was not taken over.** Its file type or size may not be on the list, or the site may be excluded in Settings, File types.

## Good to know

- Some servers do not allow resuming. Haul warns you before you pause one, because it would start over.
- A few sites give a link that works only once. Use the browser for those.
- Dragging a link from the browser's address bar does not work yet; copy it and paste it instead.

## Keyboard

**⌘N** add a download · **⌘V** paste a link · **⌘,** Settings · **⌘Q** quit
